# Análise de Concorrência em Cotas Públicas – UEPG

Dashboard interativo para análise de **candidatos**, **vagas** e **concorrência** (candidatos por vaga) nos processos seletivos da **Universidade Estadual de Ponta Grossa (UEPG)**, no período de **2016 a 2025**.

---

## 📊 Sobre o Projeto

Este projeto apresenta uma visualização clara e interativa dos dados de concorrência em cotas públicas de 6 cursos da UEPG.  
É possível analisar separadamente:

- Quantidade de **candidatos**
- Quantidade de **vagas**
- Razão **Candidatos / Vaga**

Os dados são exibidos por tipo de cota e por ano.

## ✨ Funcionalidades

- Gráficos de linha interativos por curso
- Alternância entre **Candidatos**, **Vagas** e **Cand/Vaga**
- Botão **Expandir** para visualização ampliada do gráfico
- Tabela detalhada com filtro por curso, ano ou tipo de cota
- Respostas automáticas para questões de análise
- Tema escuro com destaque em vermelho
- Totalmente responsivo
